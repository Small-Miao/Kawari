# 设计

## 决策

采用服务器现有 Lua VM 和原生 Director API。与继续增加 C# 适配层相比，不再维护进程协议、双时钟和两套状态；与逐副本零散回调相比，共享 Timeline、Scene、Actors 组件，定义按 Timelines / Actions / Statuses / Scenes 分离。

时间轴支持显式阶段和节点、进入/更新/退出回调、条件及超时、节点内定时事件。录像仅作为节点表现素材，真实目标/命中/死亡由服务器控制。场景统一管理 EObj 的生成、动画和移除，MapEffect 初始快照、切换及重置。Boss 控制参考原 Motion，提供移动/跟随/最高仇恨朝向和停止，施法时可锁定朝向。

C# 桥接从编译和运行路径移除，旧工程和配置转存归档供参考；运行不依赖 .NET。`!timeline status/reset/stop/reload` 使用原生 Lua，reload 先在候选 VM 验证初始化，再替换和清理旧轮次。

## 边界及验证

当前改造覆盖正在开发的绝本控制结构；不把尚未完成的亚历山大机制标成完整复原。凯夫卡当前默认 P2 一运，P5 定义保留可选入口。验证时间轴等待/超时/取消、场景对象生命周期、Boss 移动朝向、单人与八人 P2、三绝旧表现回归。回归通过后备份世界服并部署。
