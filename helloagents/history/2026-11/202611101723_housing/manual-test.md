# 个人住宅手工测试清单

使用当前国服客户端构建 `14251465`、本次改动构建出的世界服和两个不同的测试角色 A、B。停止旧世界服后，在仓库根目录用 `cargo build -p kawari-world --offline` 构建并启动新版，或直接启动已生成的 `target/housing-entrance-position/kawari-world.exe`。新版世界服首次启动会执行住宅迁移。准备足够金币、一件室内家具、一件庭院家具及对应地区和尺寸的房产证书。国服原生个人购地要求战斗职业达到 50 级，且当前军团军衔达到 9。调试权限角色可用 `//gm gc 2` 加入双蛇党，再用 `//gm gcrank 9` 准备军衔。

可用海雾村 3 号小地块开始，木制海滨小屋房产证书物品 ID 为 `6320`，用 `6323` 验证中型证书被拒绝。跨区和竞购测试使用尚无地块的角色或另一份测试数据库。

| 优先级 | 操作 | 预期 |
|---|---|---|
| P0 | 从森都水晶打开薰衣草苗圃的指定小区列表。预览 1 区、2 区和 30 区，每次查看「1–30号」和「31–60号」，再进入其中两个区 | 两个页签各显示 30 块地，空地有价格，已购地块显示房主。切换区号后列表与地图对应 |
| P0 | A、B 分别到同地区、不同区的同一地块，再让 B 进入 A 所在区 | 不同区的角色、房屋和家具互相隔离，同一区可以看到对方 |
| P0 | 在空地点击告示牌，选个人购买。取消一次，再确认购买 | 显示该地块的非零标价，购买确认框正常出现。取消时不扣款，确认后只扣一次标价，地块和个人房产列表更新 |
| P0 | 分别走到空地和刚购入的未建地块旁，检查告示牌和入口。建房后让同区角色 B 在原地观察 | 空地和未建地都能查看告示牌，均无「进入房屋」物件。建成后同区双方都能看到入口，房主可进入，访客仍受权限限制 |
| P0 | 用金币不足的角色购买。再让两个无地角色同时尝试购买同一块空地 | 金币不足时余额、地块均不变。竞购只有一人成功，失败角色余额不变 |
| P0 | A 重复购买原地块、再购买其他地块。B 离开告示牌后尝试 `!housing buy 3` | 各操作都被拒绝，不扣款，也不更改任何地块 |
| P0 | A 在已购地块使用原生建房菜单选择 `6320`，确认前先取消一次，再重新确认。必要时使用 `!housing build 6320` | 取消时物品、地块不变。确认后消耗一张证书，房屋出现，同区 B 能看到房屋，告示牌显示房主 |
| P0 | 对同一小地块尝试错误地区、错误尺寸的许可证。建成后再重复建房 | 证书不消耗，房屋状态不变 |
| P0 | 房主 A 和访客 B 依次右键同一间开放住宅的房门 | 两人经正常切区加载后进入同一室内，家具和玩家同步可见 |
| P0 | 在海雾村 5 号地等大型住宅，站在房门附近且离告示牌超过 18 米时右键房门，再从室内出门 | 正常进屋，离开后落在原区该房门外 |
| P0 | A 对已建住宅输入 `!housing close`，两人重新尝试进屋。然后 A 输入 `!housing open`，B 再点房门进入 | 关闭时 A 仍可进入，B 无法进入。重新开放后 B 能从房门进入 |
| P0 | A 用室内家具界面放置、移动、旋转、收纳、重新摆放、取回家具，B 旁观 | A 与 B 看到同一布局。一次操作只移动一个物品，跨背包及仓库不会复制或丢失 |
| P0 | A 在庭院摆放庭具、旋转并收纳，再从庭院仓库取出。同区 B 旁观 | 仅该地块显示庭具。位置与角度同步。室内、庭院家具无法通过错误类别混放 |
| P0 | B 尝试编辑家具及改变灯光。A 放置家具后更改灯光，并确认两人退出再进入 | B 的编辑被拒绝，家具和金币不变。A 的家具与灯光在重新进屋后保留 |
| P0 | A、B 从原生出门交互离开。A 在房屋内或非第 1 区下线并重新登录，再重启世界服重试 | 出门回原区该房门外。重登位置、房屋外观、所有权、家具、仓库和灯光均正确 |
| P1 | 让 A 在扩建区 31–60 号地执行购买、建房、摆庭具并重新进入。随后用住宅水晶切换主区和扩建区 | 地址始终落在正确分区。两个分区相同本地序号的地块互不串数据 |
| P1 | A 在第 2 区或家中进入副本，再退出副本 | 回到原区或原房屋，住宅状态正确 |
| P1 | 填满个人背包，尝试从住宅仓库取出家具。再分别接近房屋及庭院槽位上限 | 取回失败时家具仍在仓库。达到上限后额外家具不会被消耗 |
| P1 | B 在开放时进入并下线，A 关闭访客，B 再登录 | B 回到对应住宅区，房屋保持关闭，重新点击门无法进入 |
| P1 | 用升级前曾停留在演示室内的角色启动旧存档 | 角色迁回对应住宅区入口，既有角色背包和非住宅数据正常 |

如果客户端表现与预期不同，记录地区、区号、地块号、操作步骤，以及客户端回包或世界服日志。优先保留告示牌返回值、建房请求 659、事件 0xB0095，以及主区和扩建区的 `HouseList` 与 `FurnitureList`。
