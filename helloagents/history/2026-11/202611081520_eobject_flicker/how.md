# 方案

优先以最小改动修复帧间状态问题，避免用停止动画或替换材质掩盖问题。比较方案：直接禁用后处理可以定位但会改变视觉；更换渲染后端影响过大。本次选择连续帧诊断，核对曝光、渲染目标、清屏及预览重建路径，依据证据修正。

使用应用自身 GPU 读回捕获 64 个连续帧，记录亮度、黑色比例及曝光，比较奇偶帧，单独验证以太之光和 AVFX。诊断只通过环境变量启用，平时不读取像素或写诊断文件。

## 最终方案

前两版调整无效后，改为整窗 RGBA8 / DEPTH24_STENCIL8 中间缓冲：先完成 UI 与三维回调，再 blit 到窗口后缓冲。通过 egui_glow 的实际 intermediate_fbo 将场景回调接回正确目标；窗口上不再提前清屏。保留 VSync，移除 glFinish。缩放时重建附件，退出时释放。

同版本 GUI 源码归档经 SHA-256 校验后在本项目缓存中打补丁，记录补丁与许可证。验证覆盖模型、AVFX、连续帧、三次窗口尺寸变化、11 项原回归及干净归档补丁重放。屏幕闪烁结果以用户实机反馈为准；用户已确认 1.0.3 正常。
