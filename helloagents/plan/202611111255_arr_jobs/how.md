# 技术设计

保留现有 Rust Job 生命周期及 Lua 兼容路径，新增职业按模块实现。先只读解析归档并输出匿名动作、状态、量谱和实体证据；从本地 Action、ActionTransient、Trait、TraitTransient、Status 导出等级与特性。官方职业资料用于解释机制，国服数据决定版本参数；必要时通过 IDA 验证量谱、替换和施法细节。

按依赖顺序实现：战士 → 暗黑骑士 → 绝枪战士 → 学者 → 贤者 → 机工士 → 武僧 → 武士 → 舞者 → 蝰蛇剑士 → 赤魔法师 → 钐镰客。已存在的骑士、白魔、黑魔、占星、召唤、诗人和画家保持现状，新增共用逻辑必须运行其回归。

共用能力按实际需要扩展：Job 原生效果/范围结果接缝、资源校验、状态/护盾及职业演员回调，不用硬编码录像播放代替战斗逻辑。技能条件、消耗、等级、伤害治疗、状态、AoE 衰减、冷却充能、死亡/切职/换区及多人归属逐项审计。

原始录像不改写，不把玩家身份写入知识库。不连接外部服务器；本机部署前先完成代码和测试，再根据当前在线状态决定切换时机。
