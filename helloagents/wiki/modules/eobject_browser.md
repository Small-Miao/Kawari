# EObject 离线浏览器

## 目标与入口

用户要求离开游戏运行环境，按 EObj ID 查看外观与其内部时间线。程序是独立 Windows x64 桌面应用，使用自己的 OpenGL 窗口读取本地 SqPack，不注入游戏、不需要卫月、不连接世界服，也不请求在线资源服务。

- 源码：`tools/EObjectBrowser`。
- 发布：`target/EObjectBrowser-1.0.3/EObjectBrowser.exe`（旧版保留）。
- 默认游戏目录：`D:\Games\FFXIVCN`，可接受根目录、`game` 或 `sqpack`。
- 使用和重建说明：`tools/EObjectBrowser/README.md`。

## 架构

`EObj → ExportedSG → SGB → 子物件 / MDL / MTRL / TEX / AVFX / TMB`。目录由当前本地国服 CSV 导出，包含 15,513 个 ID，11,407 项关联 SGB；实际模型、材质、着色器、粒子和时间线始终从选中的游戏安装读取。

渲染使用固定提交 `4aabd2e9bc0abd9c68925af13bb7ae86922297ee` 的 XIViewer。中文前端在 `eobject.rs`，引擎最小变更保存在 `engine.patch` 与 `ironworks.patch`；`Engine/` 是可重建缓存，不进入父仓库版本控制。`build.ps1` 校验提交、幂等应用补丁、复制前端、执行回归并发布；使用上游 Cargo.lock 固定依赖。

前端仅创建 `InstallLocation::Sqpack` 和本地 schema provider。远程 API 地址为空，额外补丁拒绝空 API 的远程路径索引请求；未调用上游在线字体、报告、下载、GitHub schema 与服务器 UI。

## 功能

- EObj ID、名称、资源路径查询，支持筛选有独立 SGB 的物件。
- 自有三维视窗渲染模型、游戏着色器和 AVFX；镜头移动、完整几何取景、播放/暂停、变速、进度条与截图。
- 根节点层级、位置、子 SGB 打开/返回、资源路径复制。
- SGB 内部时间线 SubId、名称、循环/自动播放、持续时间、Actor→实例绑定与命令明细。
- 独立 AVFX 预览，默认每 5 秒重复；与作者时间线区分标记。
- 导出物件分析 JSON，不导出游戏素材。

## 重要边界

当前执行变换轨道 C013 / C018 及引擎原有自转、重复运动。C019、C056、C057、C058、C059、C133 等仅解析，界面明确显示“仅解析，未执行”。未知控制指令不推测为播放/隐藏操作；手动 AVFX 也不代表整个物件演出已复原。

SubId 不是客户端槽位或服务器 ActorControl 动画索引。必须结合录像、客户端布局绑定另行核对；本浏览器不把不同来源的编号强行对应。

没有 ExportedSG 的 EObj 可能由地图布局赋予外观或只用于逻辑。例如绝亚 2007457 不能凭 ID 得出独立模型。界面给出说明，并可输入实际 SGB 路径继续查看。未知 ID、无效安装目录、非法资源路径和读文件失败也有明确反馈。

目录是 CSV 快照，不能替代所选安装的版本检测；新版 CSV 可用 `export_catalog.py` 更新后重建。资源缺失时不自动下载或回退到别的游戏版本。独立渲染在材质、光照与部分 AVFX 运算上可能和游戏客户端存在差异。

## 整窗闪烁反馈（1.0.1）

用户澄清是包括文字和按钮在内的整窗闪烁。新增 `render_probe.rs`，显式设置环境变量后读回测试实例自己绘制的 64 个连续帧；分别对完整窗口与禁用三维绘制的纯界面进行对照。两种情况下静态目录区域像素哈希均完全相同，GPU 生成的帧没有复现用户观察到的屏幕闪烁。

1.0.1 改用完全不透明清屏色并明确关闭窗口透明；播放阶段使用 VSync 的连续刷新，不再叠加每 16ms 的定时器，静止页依靠输入与资源加载事件重绘；多次布局时只在首个 pass 推进播放时间。保留原模型和 AVFX 绘制方式，未通过停掉动画掩盖问题。

这组连续帧未能复现屏幕表现，不能将它当作修复证据；后续用户确认 1.0.1 仍整窗闪烁。诊断文件位于 `target/eobj-research/full-ui-baseline`、`ui-only-baseline`；正常运行不进行 GPU 读回和诊断文件写入。

### 后续复验与 1.0.2 提交同步候选

### 1.0.3 整窗中间缓冲（用户确认正常）

将 UI、文字和三维回调整帧绘制到独立 RGBA8 / DEPTH24_STENCIL8 缓冲，完成后通过一次全窗 blit 复制到默认后缓冲，再由 eframe 交换缓冲。停止在窗口表面进行早期清屏；不是隐藏动画或停掉三维。`Painter::intermediate_fbo` 返回当前整窗目标，原模型与场景回调可正常恢复目标。保留 VSync，无 `glFinish` 强制等待。

缓冲按物理窗口尺寸分配；先成功创建新附件后再释放旧附件，创建失败会清理已分配资源；退出时统一释放。当前 EObject 前端只使用一个 egui 根窗口，原生文件对话框不经过此自定义绘制路径。合成选项默认关闭，仅由 EObject 前端显式启用，不改变 XIViewer 其他入口。

`prepare_gui_deps.py` 校验 eframe / egui_glow 0.35.0 原始归档，在项目缓存展开，再应用 `eframe.patch` / `egui_glow.patch` 和独立 `glow_compositor.rs`。未修改全局 Cargo 缓存。已用干净、校验过的归档重新应用补丁，验证源码完全一致及反向检查，证据 `target/eobj-research/gui-pristine/verification.json`。
