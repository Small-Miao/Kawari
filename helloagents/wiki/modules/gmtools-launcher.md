# Kawari 启动器与 GMTools

2026-11-11 新版完整包位于 `target/Kawari-Launcher-Dalamud-GMTools-0.3.0-win-x64.zip`，随包提供国服卫月 Soil `26-11-10-01`、GMTools 0.3.0 和 .NET 10.0.12 x64 桌面运行时，匹配客户端 `2026.11.03.0000.0000`。解压后运行同级 EXE，保留 `dalamud-cn` 和 `plugins`。

已移除游戏配置同步、按角色覆盖、自动角色模板和相关的角色名导入。新版读取旧启动器设置时会跳过这些已移除的字段。

### IDA 与配置样本研究记录

国服 `2026.11.03.0000.0000` 的 IDB 与本机客户端 SHA-256 一致。函数 `0x1400D67E0` 取模块所在目录，`0x1400D6C70` 追加 `/My Games/` 和游戏配置目录名。函数 `0x14082E7D0` 以 `FFXIV_CHR%016llX` 格式化 64 位角色 ID。`0x1407B6E50` 在同一角色目录下构造配置文件路径并把写入交给队列，退出客户端后再替换可避免与该队列竞争。

本地样本中 `COMMON.DAT`、`CONTROL0.DAT` 和 `CONTROL1.DAT` 是文本配置，`ADDON.DAT`、`HOTBAR.DAT`、`KEYBIND.DAT` 和 `MACRO.DAT` 是不同类型的二进制配置。

打开随包的 `XIVLauncher.FakeLaunch.Gui.exe`，选择与 Kawari 服务器匹配的国服客户端并登录。随包版在没有保存设置时默认勾选卫月。启动后可通过游戏的 ESC 菜单或 `/gmtools` 打开 GM 面板。

2026-11-10 已将 `dalamud-cn` 更新为 Soil `26-11-10-01`，对应国服 `2026.11.03.0000.0000`，沿用 API 15 的 GMTools 和第 6 版 UI 资源。76 项分发文件哈希及启动器的本地版本解析已验证。旧卫月目录备份于 `target/dalamud-20261103-update/dalamud-cn-before-20261103`。应在启动新游戏进程时勾选卫月，已有进程需退出后重开。

登录服务支持远程 HTTP 和 HTTPS，当前部署填写 `http://login.celemiao.com`；Lobby 地址填写 `frp-arm.com`，端口 `21059`。2026-11-08 移除 GUI 对远程 HTTP 的限制，保留地址格式检查和禁止自动跳转。旧版出现“登录服务请输入 HTTPS 地址”时，需要替换启动器 EXE。

2026-11-08 针对朋友电脑启动即出现 `sdologinentry64+11DB` 的反馈，恢复原 FakeLauncher 的启动前 ArgFix：挂起创建游戏、安装 `GameArgumentInterop.Fixer`、恢复执行，再按需附加卫月。保留单 Lobby、中文参数及 HTTP 登录；独立传递子进程 Unicode 环境，修复失败仅终止本次游戏。11 项流程回归与本机无卫月游戏主窗口启动检查通过，朋友电脑和启用卫月的实际表现仍需复测。替换包为 `target/Kawari-Launcher-SDO-Fix.zip`，只需覆盖 EXE，保留原有 `dalamud-cn` 和 `plugins`。

启动器从同级的 `plugins/FFXIVGMTools` 加载插件。首次注入时，它在 Kawari 独立卫月配置中启用开发插件登记和 GMTools 的开机加载，迁移旧的 GMTools 路径并保留插件标识。之后在卫月中手动禁用的选择会被保留。

在 GM 面板的 **Debug 指令 → 进入副本（!cf）** 中可按中文副本名或 CF ID 筛选下拉菜单。选中后自动填写 ID，点击执行才发送指令。

GMTools 0.3.0 在「角色数值」和「Debug 指令 → 指定职业等级」提供中文职业下拉菜单和独立等级输入。职业项从国服 `ClassJob` 表读取，点击执行时生成 `!joblevel <职业 ID> <等级>`。两个页面使用固定原生列表行，展开期间隐藏被遮挡的操作，切页时收起菜单。

服务器聊天指令 `!job100` 需要 Debug GM 权限，用于解锁当前角色全部可升级的基础、战斗、生产和采集职业，并统一设置为 100 级。按 World 实际载入的职业表与角色等级槽位筛选。职业水晶优先发到兵装库，兵装库满时尝试普通背包，已装备或已持有的水晶不会重复发放。

服务器聊天指令 `!clearjobcrystals` 无参数，需要 Debug GM 权限。按国服物品表的职业水晶装备分类清除执行者的装备栏、兵装库与背包，立即同步槽位并保存。清除已装备水晶时重新按当前主手判定职业，必要时按常规职业切换逻辑卸下不兼容装备。

服务器聊天指令 `!init` 无参数，需要 Debug GM 权限。对当前角色应用 `!job100` 的等级和水晶发放逻辑，解锁传送、染色、武具投影和投影模板，单独完成美容师任务 `1210`，并按 `!skipintro` 解锁全部功能、标记全部任务完成、传送至利姆萨·罗敏萨。每次执行发放 1000 万金币。重新登录后刷新完整解锁状态。

服务器聊天指令 `!callall` 无参数，需要 Debug GM 权限。将当前 World 中已经载入场景的其他在线玩家传送到执行者的位置和朝向，目标为执行者所在的实际实例。执行者留在原地，仍在加载或正在断开连接的玩家会被跳过。

服务器聊天指令 `!lb3` 无参数，需要 Debug GM 权限。在当前脚本副本中将共享极限技量谱补满至 30,000（每段 10,000），实例内玩家同步显示。可以在开战前补满，战斗开始后按原有职业、状态及消耗规则释放。

GMTools 0.2.2 起，副本下拉复用固定原生行，筛选和开合期间保持节点归属不变。若旧版在关闭面板时崩溃，请重新启动游戏以加载新版。

重新发布时，将 GMTools 的完整构建产物目录作为 `KawariGmToolsPath` 传给 GUI 项目，再把匹配的国服卫月目录放到发布目录的 `dalamud-cn`。分发时保留这两个目录与可执行文件同级。
