## 实机反馈与表现修复

用户反馈三本过场均不正确，欧米茄 Boss 有敌对列表但模型不可见、BGM 不变、天箭地火位置/方向错误，绝龙诗场景未切换、过场缺模型和预兆。原版本没有通过实机验收。

已定位并修正以下实现差异，仍须客户端复验：

- NPC 原始布局 ID 曾被 BNpcBase ID 覆盖；现在提取并保留布局与模型 ID，使原生演出能够关联演员。Boss 死亡回调继续使用注册键，避免改变脚本通关判断。
- 过场/BGM 先前以零来源的普通包广播；改用玩家自身控制消息，BGM 缓存并在入场完成时补发。
- 首次入场和重置都使用录像最近一次完整 MapEffect 基线，再按时间顺序恢复转场前增量；排除前次全灭残留，禁止预先发送最终阶段场景。场景缓存重发保留顺序。
- 恢复录像天气与渐变时长。龙诗转场出现天气 170、随后 47；光暗最终天气 108；欧米茄最终天气 175。入场恢复各自前一阶段天气。
- 读条保留录像 `omen_delay`。脚本定位改用 ActorSetPos，Helper 在技能表现前精确定位，避免平滑移动造成表现与判定错位。
- Boss 战斗中按当前仇恨目标转向，读条期间锁定；忽略录像玩家引起的战斗期 Boss 转向，保留转场动作。

验证扩展到演员真实布局/模型、非零预兆延迟、天气事件、等待木桩时不消费时间轴及初始 MapEffect 快照。172 项世界库测试通过；这些测试不能代替视觉验收。

### 第二轮定位（尚待实机复验）

上轮欧米茄实测仍是背景变化、模型不可见和 BGM 不切换。龙诗缺失的是塔圈、核爆、地火等地面范围提示。

- IDA 数据库与游戏文件 SHA256 一致（`958b78e278ad896493c484eb313ff605ab41edefef74f92b0ee078e69b281bf9`）。`0x140B38BE0` 的 415 分支通过虚表 +328 添加渲染隐藏标志 13，不是位置刷新。移除每次读条前和伊弗利特分身定位后的误发，协议与 Lua API 更名为 `HideActor` / `hide_actor`。
- Spawn 标志 `0x20000` 映射隐藏位 14（`0x1408CEAB0`）。原录像最终 Boss 确实以隐藏状态创建，但其后如何解除仍需结合现场状态确认，不能把可选中等同于可见。
- 原录像 DirectorVars flag=1，脚本此前为 0；新增设置与同步接口。过场音乐函数 `0x140B6E030` 受导演内部状态抑制，尚未证明此项独自足以恢复 BGM。
- ActorCast 预兆使用包内独立坐标（`0x14090CEF0`），现在与演员位置分开保存，并保留 spell_id。动态引导覆盖预兆落点，实时选人结果用于目标字段。
- 补回 417 Helper 归属和 607 演员表现事件；目标均转换为本实例 NPC ID。607 淡入时长按百分之一秒。Spawn 补齐模型属性及初始动画。
- 更新期间旧世界服读入新 Lua，缺少 `set_director_flag` 曾导致 onSetup 中断、木桩和场景均未初始化。已加接口兼容保护，程序与脚本仍应整批部署后新建实例测试。

`tools/extract_ultimate_finals.py` 读取用户提供的 FFXIVREPLAY v5 文件，原文件保持不变。输出匿名 NPC 别名、相对时间、技能及演员/场景事件，不保存玩家姓名、玩家对象 ID 或原受击名单。校验和、截取窗口和事件计数在 `tools/ultimate-evidence/evidence.json`。

运行生成器时显式提供 `--recordings` 和 `--bossmod` 路径。生成数据只写到 `tools/ultimate-evidence`；五个 `*_rules.lua` 装配手工维护的 `Definitions`，完全不加载该证据目录。`CONTENT_DIR` 由世界服按实际 content 脚本目录设置。

提取 Spawn、位移、读条、动作、MapEffect、BGM、模型/动画/可选中/可见状态、NPC 连线和 Director 演出。Director 演出仅允许指定范围，并排除原副本时限及通关/奖励事件。动作方向使用 ActionEffect 的正确字段偏移。角色装备与外观未逐字段复制，NPC 外观依赖当前客户端表与 BNpcBase 模板。

## 实时机制

- 公共机制：位置快照、圆形/环形/矩形/扇形、远近选人、仇恨顺位、分伤、人数及职业检查、前排坦克、Buff 叠层惩罚、场外死亡和狂暴兜底。伤害来源归属最终 Boss，表现来源可为 Helper。
- 龙诗：三位一体仇恨与最近玩家判定、暗光耐性叠层、核爆距离伤害、死亡轮回塔和物理塔。塔至少一人而非强制 3/3/2，允许无敌单吃。
- 光暗：双侧分摊、双翼方向与远近死刑、两人塔、双侧光暗引导和残留直线。光暗耐性只给直线首人，短魔法易伤给实际命中玩家。
- 欧米茄：首仇恨/最远普攻、近距离双死刑与分摊、宇宙箭/波动炮、八人直线与双坦克前排、天体、核爆与魔数。小彗星在核爆标记后约 0.3 秒检查，大陨石当前在约 8.3 秒检查；大陨石时点待失败录像校准。
- 三级极限技仅在 Director 显式启用槽位的实例中接入：职业校验、消耗、坦克减伤、治疗净化/复活/回蓝、输出范围伤害；欧米茄潜能返还一次，死亡失去潜能。魔数在实际 6 秒到期时检查是否已被净化。

## 证据差异与尚未复原的范围

1. 每本只有一份成功录像，地面图案与阶段顺序固定为该录像；不覆盖全部随机变体。原录像在狂暴期间击杀 Boss，未覆盖的失败动画/完整狂暴尾段采用兜底失败判定。
2. 伤害、距离衰减和输出 LB 为可调练习初值，不是原始装等/武器公式。当前仅覆盖部分常用减伤、护盾及无敌状态；不保证全部职业技能联动，尤其完整死而复生生命周期。
3. TOP 宇宙俯冲分摊当前选第三近，依据 Meru 攻略；本地 BossMod 注释写最远，成功录像同组站位不能充分区分，需专门站位测试核实。
4. Director 包、模型状态和动画事件已提取并排程；镜头、控制恢复、地图重置、演员外观及动作特效仍须客户端核验。离线 Lua 测试不能证明视觉正确。
5. 持续同一实例内的 Lua 已加载；更改脚本后应离开并新建实例进行复测。
