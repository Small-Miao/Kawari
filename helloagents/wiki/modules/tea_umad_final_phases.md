# 绝亚 P4 与绝妖星 P5

## 入口与结构

当前使用独立 C# 宿主，入口及编辑说明见 [C# 副本控制](csharp_encounters.md)。`!cf 694` 对应绝亚 P4，`!cf 1094` 对应绝妖星 P5。编号来自当前国服 ContentFinderCondition；887 / 1363 是区域 ID，不能混用。下文较早的 Lua 编辑路径保留作历史对照，新的运行定义在 `resources/encounters/Definitions` 对应 `.cs` 文件。

入场为上一阶段场景并放置木桩；触发后绝亚约 73 秒、妖星约 37 秒开放最终本体。结束录像或到达狂暴不会通关，只有实际最终 Boss 死亡才完成副本。`!timeline stop/reset/reload` 沿用公共生命周期，清理本轮延时任务、Buff、EObj 和演员。单人观察可开启 `!godmode on`，但人数不足仍会产生机制失败判定。

编辑入口：
- `Definitions/Timelines/d2az.lua` / `z3oy.lua`：节点与时长。
- `Definitions/Actions/TEA` / `UMAD`：具体技能、选人、几何与结算。
- `Definitions/Statuses/TEA.lua` / `UMAD.lua`：Buff。
- `Definitions/Scenes/d2az.lua` / `z3oy.lua`：动态场景行为。
- `Definitions/Scenes/d2az/Initial.lua` / `z3oy/Initial.lua`：直接恢复入场地图、音乐、天气与静态物件。
- `Definitions/Scenes/d2az/` / `z3oy/` 的具名机制文件：直接调用 MapEffect、EObj、音乐、天气和 Director。
- `Definitions/Sequences/d2az/` / `z3oy/` 的同名文件：显式演员、读条、技能、状态和演出；演员模板位于 `Definitions/Actors`。

DSR / FRU / TOP 同样按节点拆成显式序列和场景函数。`common.lua` 仅保留生命周期，`mechanics.lua` 分发实时判定；旧 `*_data.lua` 和 Scenes/Records 已移至 `tools/ultimate-evidence`，完全退出五本运行依赖。

## 证据与边界

使用用户提供的 `亚历山大绝境战 2026.11.04 21.26.24.dat`、`妖星乱舞绝境战 2026.11.03 17.11.19.dat`，原文件只读。绝亚最终段提取 40 个演员、1377 个事件；每阶段八个投影。身份在导出时匿名化，外观取当前队伍。

机制对照本地 BossmodRebornCN 的 TEA 模块、[Perfect Alexander 攻略](https://www.icy-veins.com/ffxiv/the-epic-of-alexander-ultimate-guides-perfect-alexander) 和 [妖星 P5 作者攻略](https://kanatan.info/archives/41984416.html)。网络攻略存在早期推测，出现差异优先保留录像与专门实测证据。

尚未验收的具体边界：
- 图案与分支以提供的成功录像为准，未覆盖全部随机变体；非致死伤害仍为练习初值。
- 绝亚录像在时间牢狱读条约 5 秒时击杀 Boss；后续七塔及狂暴由机制定义补齐，不能声称来自完整尾段录像。
- 妖星橙圈四个格点及 MapEffect 对应来自录像；按当前玩家象限选择是现阶段推断，未覆盖攻略中不确定的全部随机诱导规则。
- 行动/静止检测覆盖水平位移和动作计数，跳跃原地等细节还需实机核对。
- 客户端镜头、角色投影外观、完整特效和八人机制平衡尚待实机验收。TOP 既有额外 LB 特效问题仍在原待办中。
