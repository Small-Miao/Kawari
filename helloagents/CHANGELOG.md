- 按最新要求将全部八个已有副本入口及保留的凯夫卡 P2 迁至独立 C# 宿主；主时间轴使用原 MechanicSim 的 ITimeLineDefinition / Build / TimeLineDef / Phase / Node / TimeSpan / OnTimeLineEvent / RaidManager.Instance 写法，原工程未改动。

- 验证通过：188 项世界服测试、99 项 C# 断言、50,480 个实际原生批次及 2 项 C# 中间层集成测试。世界服已重启，PID 60808，健康检查 200；现有客户端视觉问题继续单独跟踪。
